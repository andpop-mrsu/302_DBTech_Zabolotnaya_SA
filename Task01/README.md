# Лабораторная работа 1. Подготовка окружения для выполнения заданий и интерактивной работы с СУБД SQLite

## Структура файлов в каталоге Task01:

* `ratings.csv` - исходный файл с пользовательскими оценками фильмов.
* `movies.csv` - исходный файл со списком фильмов и их жанрами.
* `tags.csv` - исходный файл со пользовательскими тегами.
* `links.csv` - исходный файл с идентификаторами фильмов в внешних базах данных (IMDb, TMDb).
* `ratings_count.txt` - текстовый файл с подсчетом количества оценок для минимального и максимального `userid`.
* `sqlite.txt` - файл с версией установленной СУБД SQLite и списком поддерживаемых режимов вывода (`mode`).
* `README.md` - файл с описанием структуры данных и состава файлов папки.
